# The Royal Court (C# port, unreleased)
Crusader Kings III mod manager: fast, auto-sorting, with a conflict finder. C# on .NET 10 with Avalonia; ships as one self-contained TheRoyalCourt.exe.
Build: `dotnet build RoyalCourt.sln -c Release`. Tests: `cd tests/RoyalCourt.Tests && dotnet test`. See PORT_STATUS.md for what is verified and what still needs real-Windows testing.
